## UC-005 매매일지 등록

### 사전 조건

사용자가 로그인되어 있다.

### 기본 흐름

1. 사용자가 매매일지 등록 화면으로 이동한다.
2. 종목명, 매수일, 매수가 등의 데이터를 입력한다.
3. 등록 버튼을 누른다.
4. 서버가 입력값을 검증한다.
5. 정상적인 경우 DB에 저장한다.
6. 매매일지 목록 화면으로 이동한다.

### 예외 흐름

필수값이 누락된 경우 등록하지 않고 오류 메시지를 표시한다.

### 완료 조건

TRADE 테이블에 현재 사용자의 거래 정보가 저장되어 있다.
