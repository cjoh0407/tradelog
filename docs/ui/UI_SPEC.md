## UI-006 매매일지 등록

### 목적

새로운 매매 기록을 등록한다.

### 입력 항목

| 항목 | 필수 | 입력 형식 | 설명 |
|---|---|---|---|
| 종목명 | O | Text | 거래 종목 |
| 매수일 | O | Date | 매수 날짜 |
| 매수가 | O | Number | 매수 가격 |
| 수량 | O | Number | 매수 수량 |
| 매도일 | X | Date | 매도 완료 후 입력 |
| 매도가 | X | Number | 매도 완료 후 입력 |
| 매수 이유 | X | Textarea | 진입 근거 |
| 복기 | X | Textarea | 거래 후 평가 |

### 동작

등록 버튼
→ 입력값 검증
→ 저장
→ 매매일지 목록 이동

취소 버튼
→ 매매일지 목록 이동
