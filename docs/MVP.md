# TradeLog MVP

## 목표

사용자가 로그인하여 자신의 매매 기록을
등록 → 조회 → 수정 → 삭제할 수 있는 최소 기능을 완성한다.

## MVP 포함

| 기능 | 포함 여부 |
|---|---|
| 회원가입 | O |
| 로그인 / 로그아웃 | O |
| 아이디 중복 확인 | O |
| 매매일지 등록 | O |
| 매매일지 목록 | O |
| 매매일지 상세 | O |
| 매매일지 수정 | O |
| 매매일지 삭제 | O |
| 기본 대시보드 | O |

## MVP 제외

| 기능 | 이유 |
|---|---|
| 증권 시세 API | 핵심 CRUD 완료 후 고려 |
| OAuth 로그인 | MVP 범위를 벗어남 |
| 게시판 / 커뮤니티 | 프로젝트 핵심 목적과 무관 |
| 자동 종목 검색 | 추후 개선 |
| 모바일 앱 | Web MVP 이후 고려 |

## MVP 완료 기준

회원가입
→ 로그인
→ 매매 등록
→ 목록 조회
→ 상세 조회
→ 수정
→ 삭제

전체 흐름이 정상 동작하고
사용자별 데이터가 분리되면 MVP 완료로 판단한다.
